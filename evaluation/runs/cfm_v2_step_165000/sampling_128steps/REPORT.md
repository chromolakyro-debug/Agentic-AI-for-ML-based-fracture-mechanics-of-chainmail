# Evaluation cfm_v2_step_165000_128steps

采用独立冻结的24个用户选定网格中点及10个固定seeds；未训练或修改模型。

Checkpoint：`cfm_v2/run/evaluation_checkpoints/best_val_165000.pt`，`ema`权重；hash见manifest。数据版本`curated_eight_classes_v1_7857`，共7857张，其中6285张训练图用于retrieval。实际模型信息及训练augmentation见model_info.json；本次按用户要求在检索距离中比较原轴序和交换轴序，选择较小值，每个来源只占一个名额。

定义为`s=0.5[log(Ex/Esoft)+log(Ey/Esoft)]`、`a=log(Ex/Ey)`，`Esoft=1`。模量沿用原FEM单位。距离为`d(q,p)=sqrt(((Ex_q-Ex_p)/1)^2+((Ey_q-Ey_p)/1)^2)`；固定尺度不由生成结果拟合。原输出保留float32；阈值`raw>=0`为白色软材料1，黑色硬材料0。FEM对保存的二值数组逐图求解，HTML使用同一材料场，无插值、缩放或反色。

实际完成240张生成，FEM有效240/240，失败0。Ex/Ey各相对误差≤5%的联合命中为69/240；`|Δs|≤log(1.05)`且`|Δa|≤log(1.10)`为106/240。失败计入分母。FEM residual、反力和能量检查保留在results.json/csv中。
