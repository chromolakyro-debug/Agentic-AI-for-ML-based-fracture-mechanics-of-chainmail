# CFM Evaluation：20k与125k

已在evaluation/实现并实际运行可复现pipeline；本轮没有训练，也没有修改原数据、metadata、split或checkpoint。两个模型各完成用户圈定的24个target × 相同10个seeds，共480张正式二值图，真实FEM有效480/480。另完成80张development诊断图及原图/旋转/镜像的独立FEM检查；这些不混入正式统计。

Targets来自用户补充的红圈图：从下往上R1/R6选C3–C4，R2/R5选C2–C5，R3/R4全选。中点使用原6×6等宽网格的精确bin edges，未从截图估计数值。定义为`s=0.5[log(Ex/Esoft)+log(Ey/Esoft)]`、`a=log(Ex/Ey)`，`Esoft=1`。这张网格虽来自整理后数据的展示，两个旧checkpoint的retrieval始终只使用它们对应的旧6,400张训练图。

两个模型均为11,529,633参数Conditional U-Net，使用EMA；125k是此前最终选择的best.pt，120k的best-validation.pt未混用。采样为64步midpoint、batch10、CUDA bfloat16网络与float32积分状态，设备RTX4090。raw float32完整保存，`raw>=0`为白色软材料1，黑色硬材料0；FEM与HTML使用相同二值像素。原Q4有限试件FEM：224×224、40×40×2、硬/软模量10/1、Poisson比0.3、横向自由拉伸、tol=1e-9。没有反色或改变边界条件。

距离固定为`d_mech=sqrt((Ex_FEM-Ex_target)^2+(Ey_FEM-Ey_target)^2)`，单位沿用原FEM；没有从生成结果拟合尺度。误差始终按固定全局坐标计算。retrieval则比较原轴序和交换轴序，取较小距离，每个原始来源只占一个名额，显示未旋转的原图并分别标出original/matched值。旧模型训练记录为augmentation=none；本次轴交换retrieval按用户要求启用，因此它拥有旧模型训练时未使用的旋转选择自由度。

s/a阈值预先固定为`|Δs|≤log(1.05)`且`|Δa|≤log(1.10)`，失败计入分母。125k平均距离下降29.8%，23/24个target改善，但未达到高命中率。不能把本次新24格的命中率与旧20个target面板直接比较。

观察到的规律：

- 在固定`a=±0.18449`扫描s时，125k的平均`s_FEM`响应斜率分别为1.018、1.037；各seed的`a_FEM`交叉斜率绝对值平均为0.0206、0.0293，总体刚度控制较好。固定s扫描a仍有压缩：最低s列的a响应斜率仅0.521，最高s列0.672。极端正a行仅有两个target，`a_FEM`随s的交叉斜率为1.032，独立性明显不足。这些是指定有限扫描上的描述性拟合，不是普遍物理导数或统计显著性结论。
- 最明显的退步是T23：`s=0.95941,a=0.92243`，mean(d)从0.97298升到1.27113，125k的s/a命中0/10，平均`Δa=-0.52719`。该格旧训练集原轴序来源数为0，允许轴交换后也仅3个；T24对应0与14个。数据覆盖不足及未训练旋转增强与失败相符，但不能单独证明原因。相反，较密集区仍存在误差，所以不能将全部问题归结为稀疏性。
- 125k在正a半区的mean(d)=0.43804，负a半区为0.31847；改善并不对称。`|a|=0.92243`的四格合计s/a命中仅5/40。每格旧训练集原方向/允许交换后的来源数另存，不将8次D4记录数视作8倍独立数据。
- 同一target的training retrieval top1平均距离为0.09412，top10全部展示位置平均为0.20850，均优于普通生成的0.37825。125k经过真实FEM筛选的best-of-10平均距离为0.12928，仍需标明筛选。当前证据没有证明生成模型在纯机械精度上超过retrieval；是否提供有意义的新外观结构，留给人工审阅。

两个HTML各含24个面板、720个图片位置，Generated保持全部10个固定seeds；两组retrieval按近邻排名显示，第三行明确标出实际FEM query的seed。已展示固定前两个seeds在全部targets上的未经外观筛选样例，包含失败结构。目视可见部分极端条件下的拉长、碎片或极细轮廓，但本轮不做猫形率、diversity或memorization自动评分，也不把机械近邻当作视觉近邻。页面提供旋转、左右镜像、复位及人工评级JSON导出。

验证通过：7项核心逻辑测试；旧8,000与新7,857张数据逐图PNG/NPY/metadata/标签/划分核对；真实FEM轴交换与相位检查；故意非法材料输入的失败记录；两组retrieval的独立全训练集穷举复核；两个checkpoint初始noise完全一致；额外重新采样raw逐元素一致；HTML嵌入数值与结果表一致；两页面各720张图片加载及旋转/镜像/复位操作通过浏览器测试。缓存加入输入内容、代码及FEM库版本校验；加固cache key后的重算也保留日志。复跑验证每模型24个生成块命中，FEM复跑240/240命中、无额外求解。

每240张采样约71–81秒，8-worker FEM实际单轮约92–157秒，取决于并行CPU负载；单图FEM预检约0.9秒。首次20k完整流程约170秒；125k加固缓存后的完整流程约242秒。所有初次运行、分阶段运行及复跑耗时见comparison/execution_history.csv，未将cache命中计为新求解。

入口：runs/old_20k/index.html、runs/old_125k/index.html。每run包含mean/variance热图、s–a与Ex–Ey连线图、逐样本CSV/JSON、raw/binary arrays、FEM diagnostics、配置、代码快照和manifest。新数据adapter已验证6,285张训练图；新checkpoint尚未提供，因此仅有明确的adapter接口和绑定要求，没有伪称测试了新模型。复现和迁移步骤见README.md。小型evaluation_ai_review.zip附训练属性目录、固定targets/seeds、完整正式结果及精确binary inputs，可由verify_ai_archive.py在无完整项目时核对。
